# Renewal-equation model for typhoid outbreak-response immunization

This module reconstructs time-varying transmission from outbreak incidence and
propagates a vaccination counterfactual. Indirect protection is generated by
the modified incidence history; it is not imposed as a fixed indirect-effect
parameter.

The current analysis distinguishes two additive levels.

1. **Observation:** suspected febrile incidence is latent true typhoid plus
   other febrile illness, `S_t = T_t + F_t`. Posterior PPV draws determine the
   cumulative true-typhoid burden. `F_t` is fixed under typhoid vaccination.
2. **Transmission:** true typhoid is exogenous/background-source incidence plus
   propagated incidence, `T_t = X_t + P_t`, with
   `P_t = R_t^P sum_s w_s T_{t-s}`. This second level is run by
   `source_decomposition/run_source_decomposition.R`.

The former calculation
`theta * static + (1 - theta) * renewal` is no longer the primary model. It is
retained only as a paired structural comparator.

## Reproduce

Run from the repository root:

```powershell
Rscript renewal/run_analysis.R
Rscript source_decomposition/run_source_decomposition.R
quarto render renewal/report.qmd --to html
```

The first command builds the observation-adjusted renewal/static outputs. The
second classifies transmission mode, runs the additive source-plus-propagated
counterfactual, validates it, and compares it with the historical
theta-weighted calculation. The final render ensures the renewal report sees
the newly generated source-comparison tables.

## Model equations

For true-typhoid incidence `T_t`, total infectiousness is

```text
Lambda_t = sum_s w_s T_(t-s).
```

The pure propagated model reconstructs `R_t = T_t / Lambda_t`. The additive
source formulation instead uses

```text
T_t = X_t + P_t
P_t = R_t^P Lambda_t
```

and the vaccination counterfactual

```text
q_t   = 1 - c(t) * coverage * psi_T
X_t^v = q_t X_t
P_t^v = q_t R_t^P sum_s w_s T_(t-s)^v
T_t^v = X_t^v + P_t^v
S_t^v = T_t^v + F_t
```

Positive incidence with zero prior infectiousness is treated as an exogenous
seed. This is required for exact baseline reproduction after an initial seed or
an incidence gap.

## Principal source files

- `R/ppv.R`: observation-level PPV allocation, `S_t = T_t + F_t`.
- `R/renewal_core.R`: pure renewal and additive source counterfactuals.
- `R/scenario.R`: Sobol timing, coverage, and vaccine-effect scenarios.
- `tests/test_renewal.R`: model invariants and endpoint tests.
- `../source_decomposition/R/decompose.R`: paired additive-versus-weighted
  simulations and summaries.
- `report.qmd` and `../source_decomposition/report.qmd`: rendered explanations
  and results.

## Generated outputs

`renewal/run_analysis.R` writes standard tables, figures, `outputs/results.rds`,
and `report.html`.

`source_decomposition/run_source_decomposition.R` additionally writes:

- `tables/tab_additive_vs_theta_weighted.csv`;
- `tables/tab_additive_vs_theta_weighted_pooled.csv`;
- `tables/tab_additive_validation.csv`;
- `outputs/additive_vs_theta_weighted.rds`;
- `figures/fig_additive_vs_theta_weighted.*`; and
- `figures/fig_additive_difference.*`.

Generated module directories are intentionally gitignored.

## Key assumptions and limitations

- Only daily or weekly outbreaks satisfying the generation-interval resolution
  rule enter the renewal analysis.
- PPV fixes cumulative true-typhoid burden but does not identify its weekly
  allocation. The primary allocation is derived from excess over a flat
  background candidate, followed by non-negative truncation and PPV-conserving
  renormalisation.
- The final other-febrile residual is fixed under vaccination but is not
  necessarily perfectly flat after renormalisation.
- The source fraction is based primarily on field-investigation evidence. Curve
  shape alone did not pass the prespecified identifiability gate.
- A constant outbreak-level source fraction is a structural approximation; its
  paper/curve-derived range is reported separately from posterior uncertainty.
